# T2T Genome Assemblies

This repository contains a master list of all telomere-to-telomere (T2T) genome assemblies generated by the Logsdon lab at the University of Pennsylvania, as well as links to documentation about the generation and assembly of these genomes and the associated annotations and raw sequencing data for each genome.

All associated data from these assemblies will be hosten on AWS through their [Registry of Open Data](https://registry.opendata.aws/tcga/)


## Assemblies and Associated Sequencing Data
Assemblies are generated using a standardized long-read sequencing pipeline, incoprorating both:
- PacBio HiFi data
- Oxford Nanopore (ONT) data
- (optional) Chromatin conformation capture (Omni-C or Pore-C)
- (optional) PacBio Kinnex full-length Iso-Seq for transcriptomics and genome annotation

Assembly: PacBio HiFi, ONT, and/or Omni-C or Pore-C data were assembled with Verkko and hifiasm and optionally repaired using AssemblyRepairer.

Quality Contral: Assembly quality was determined using tools such as NucFlag, HMM-Flagger, Merqury, and quarTeT. 

Released datasets include haplotype-resolved assemblies, quality metrics, gene annotations, structural and small variant call sets, read alignments, and raw sequencing data (with methylation information when possible).
