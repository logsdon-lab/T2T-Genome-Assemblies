# T2T Genome Assemblies - Logsdon Lab

This repository contains a master list of all telomere-to-telomere genome assemblies generated by the Logsdon lab at the University of Pennsylvania, as well as links to documentation about the genration and assembly of these genomes, as well as how to gain access to the raw data and associated annotations for each genome.

All associated data from these assemblies will be hosten on AWS through their [Registry of Open Data](https://registry.opendata.aws/tcga/)


## Assemblies and Associated Data
Assemblies are generated using a standardized long-read sequencing pipeline, incoprorating both:
- PacBio HiFi long reads
- Oxford Nanopore (ONT) ultra-long reads
- (optional) chromatin conformation capture (Omni-C or Pore-C)
- (optional) PacBio Kinnex full-length Iso-Seq for transcriptomics and genome annotation.

Assembly: Assembled with Verkko and Hifiasm. Some versions may be repaired by comparing hifiasm and verkko assemblies using AssemblyRepairer.

Quality Contral: Assembly quality is determine through tools such as merqury, quarTeT, HMMFlagger and NucFlag. 

This uniform approach resolves complex genomic regions-including centromeres, segmental duplications, immune loci, and sex chromosomes. Released datasets include haplotype-resolved assemblies, gene annotations, structural and small variant call sets, read alignments, and quality metrics.
