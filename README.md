# T2T Genome Assemblies

This repository contains a master list of all telomere-to-telomere (T2T) genome assemblies generated by the Logsdon Lab at the University of Pennsylvania, as well as links to documentation about the generation and assembly of these genomes and their associated annotations and raw sequencing data.

All associated data from these assemblies will be hosted on AWS through their [Registry of Open Data](https://registry.opendata.aws/tcga/).


## Assemblies and Associated Sequencing Data
Assemblies are generated using either Verkko or hifiasm, incorporating:
- PacBio HiFi data
- Oxford Nanopore (ONT) data
- (optional) Chromatin conformation capture data (Omni-C or Pore-C)

Assemblies where then optionally repaired with AssemblyRepairer to correct errors in the genome assemblies.

Quality Contral: Assembly quality was determined using tools such as NucFlag, HMM-Flagger, Merqury, and quarTeT. 

Released datasets include haplotype-resolved assemblies, quality metrics, gene annotations, structural and small variant call sets, read alignments, and raw sequencing data (with methylation information when possible).
